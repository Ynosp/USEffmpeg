==================================================================== 三、 GitHub 專案設置與離線桌面點擊使用教學 ==================================================================== 【步驟 1：建立專案與推送到 GitHub (Ynosp/USEffmpeg)】 1. 登入 GitHub，點擊右上角「+」-> 「New repository」。 2. Repository name 設定為：USEffmpeg 3. 設定為 Public (公開)，點擊 Create repository。 4. 在本地電腦將本語系檔案更新至專案 code 中： git clone https://github.com/tejaswigowda/ffmpeg-webCLI.git cd ffmpeg-webCLI (依據本 TXT 檔案內容修改 index.html 與相關 JS 語意) git remote set-url origin https://github.com/Ynosp/USEffmpeg.git git branch -M main git push -u origin main 【步驟 2：開啟 GitHub Pages 免費線上使用】 1. 進入您在 GitHub 的專案頁面：https://github.com/Ynosp/USEffmpeg 2. 進入「Settings」 -> 左側選單「Pages」。 3. 在「Build and deployment」下的 Source 選擇「Deploy from a branch」。 4. Branch 選擇「main」 / /(root)，點擊「Save」。 5. 等待數分鐘後，您的線上轉檔網站即上線於： https://Ynosp.github.io/USEffmpeg/ 【步驟 3：下載至桌面直接點擊使用 (離線 desktop 使用)】 方法 A (最推薦 - PWA 應用程式化安裝)： 1. 用 Chrome 或 Edge 瀏覽器打開 https://Ynosp.github.io/USEffmpeg/ 2. 首次打開時點擊「載入 FFmpeg」，讓瀏覽器快取 WebAssembly 核心檔案。 3. 點擊瀏覽器網址列右側的「安裝應用程式」圖示（或選單中的「安裝 USEffmpeg」）。 4. 安裝後桌面會出現獨立圖示，之後即使「完全斷網」也能直接在桌面點擊開啟使用！ 方法 B (本地直接打開 index.html)： 1. 在 GitHub 專案頁面點擊「Code」->「Download ZIP」。 2. 解壓縮 ZIP 檔至桌面。 3. 直接雙擊打開 `index.html` 即可在瀏覽器中開啟系統使用。
